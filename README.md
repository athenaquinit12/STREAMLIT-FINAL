This Streamlit app enables users to upload a CSV or Excel file containing rice yield data and validates that the file has at least five columns. Upon successful upload, users can opt to view the raw data via a checkbox. Additionally, the app offers dropdown filters to select a column and value, dynamically displaying rows that match the selected criteria. It includes error handling to display friendly messages in case of file issues or format errors.
