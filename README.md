This app features a sidebar navigation menu to switch between topics related to Data Warehousing and Enterprise Data Management. It uses layout tools like columns and expanders for an organized, clean interface. The "Home" section introduces EDM concepts, while other pages—such as ETL Workflow, Data Quality Dashboard, and Metadata Overview—use visuals, images, and tables to convey information clearly. The result is a structured and interactive dashboard for exploring core enterprise data themes.
