In this activity, the Streamlit app connects to a public COVID-19 API to fetch and display real-time statistics across multiple countries. Users can select countries using a multiselect dropdown, and data is presented through five visualization types: bar charts for total cases, line charts for deaths and recoveries, area charts for active and critical cases, pie charts for today's data, and a scatter plot (Altair) showing tests vs. population. The app handles missing data smoothly and offers a dynamic, informative user experience.
